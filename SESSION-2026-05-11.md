## Technical Notes
- Framework: Next.js (App Router) with TypeScript
- Styling: Tailwind CSS + custom CSS variables (`--wp-charcoal`, `--wp-gold`, `--wp-sage`, `--wp-cta`, etc.)
- Hero uses Syne (display) + Newsreader (body italic) fonts via `--font-syne` and `--font-newsreader` CSS variables
- Hero accent color: `#E85D40` (coral/red-orange) — differs from the site's sage/gold palette; may want to harmonize later
- UI library: shadcn/ui components
- Database: Prisma ORM
- Storage: Supabase + Cloudflare R2
- Payments: Stripe
- Deployment: Vercel
