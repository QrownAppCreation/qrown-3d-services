## What Was Done

### 1. Homepage — Complete Rewrite (`app/page.tsx`)
**Before:** Hero was a self-contained "flyer-style" React component with coral (#E85D40) accent, embedding the 3-step process inside the hero card. Trust bar was duplicated (hero info bar + separate section). Gallery used 6 Unsplash stock images.

**After:** Mobile-first landing page with 6 distinct sections:

1. **Hero Section** — "Your love story, perfectly printed." headline (Syne 800), product image right side, inline trust badges (5–7 day turnaround, you approve first, satisfaction guaranteed), large thumb-friendly "Start Your Order" CTA (py-6 for mobile). 2. **Three Simple Steps** — Process showcase using couple 2's complete journey (reference photo → 3D render → final print) for consistency. Step number badges overlaid on images.

3. **Quick Order Section** (`#quick-order`) — Simplified 4-step funnel cards (Upload → Colors → Size → Pay) with Lucide icons. "Want more options? Try our full customiser →" escape hatch linking to the full wizard. Pricing note: "Starting at $79 · 50% deposit today, rest on approval."

4. **Gallery** — Replaced all 6 Unsplash placeholders with real product images from all 3 couples (renders, final prints, hero product shot). 2-column grid on mobile, 3-column on desktop.

5. **Products Section** — Kept product cards but tightened for mobile (2-col grid on mobile, 4-col desktop). Added "Coming soon" labels to non-topper products.

6. **Scroll-Past Warm Reminder** — "Still thinking it over?" section with Heart icon, 3 reassurance points (you approve everything, affordable, couples love them), and gentle "Start whenever you're ready" CTA. Warm and reassuring tone — not urgency-driven.

## Technical Notes
- Framework: Next.js 16 (App Router) with TypeScript
- Styling: Tailwind CSS v4 + custom CSS variables (`--wp-sage`, `--wp-gold`, `--wp-cta`, `--wp-charcoal`, etc.)
- Fonts: Geist (sans), Geist Mono, Syne (display), Newsreader (serif italic) via `next/font/google`
- UI library: shadcn/ui components
- Database: Prisma ORM with Supabase/Postgres
- Storage: Supabase + Cloudflare R2
- Payments: Stripe (50% deposit model)
- Deployment: Vercel with Analytics + Speed Insights
- Brand palette: sage #8B9D77, gold #C9A84C, burnt orange CTA #C4622D, charcoal #2C2C2A
- Navbar is now a client component (`"use client"`) for hamburger toggle state
- StickyMobileCTA is a client component with scroll listener (400px threshold)
